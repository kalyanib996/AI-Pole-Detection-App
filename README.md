Full-stack AI Pole Detection App using Ultralytics YOLO, Roboflow, Python Flask, Render, and Vercel with confidence-based image classification.

AI Pole Detection App is a full-stack computer vision application that classifies uploaded images as Pole or No Pole and returns a confidence score.
The model is built using Ultralytics YOLO, with hosted inference through Roboflow. The backend is developed with Python and Flask and deployed on Render, 
while the frontend is built with HTML, CSS, and JavaScript and deployed on Vercel. The project also uses REST APIs, CORS, environment variables, GitHub, 
Render, Vercel, and Roboflow for end-to-end development and deployment
